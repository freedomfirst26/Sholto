    SHIFT+HIMIDLOW Stems

    Drop the vocal. Keep the drums.

    Sholto splits every track into drums, vocals and instrumental. Hold a deck’s SHIFT and turn HI, MID or LOW to ride each level, or tap pads 1 to 3 on the HOT CUE page to mute one.

    DRMSVOXINST

    Got an NVIDIA graphics card? Separation runs on it by itself. Without one it runs on the processor and takes from half a minute to a few minutes per track, once.

    Space Search

    Search that fits your mix

    Press Space and type. Sholto ranks your whole library by how well each track fits the other deck: its key and its tempo, half- and double-time included.

    Type the initials and skip the rest. iltwykm finds “I Like The Way You Kiss Me”. Add bpm:124-128, key:8a or #vocal to narrow it.

    CtrlL Track List

    Build tonight’s set while you search

    Search loads into three places: Deck 1, Deck 2 and the Track List. Ctrl L adds the highlighted song, a whole crate or a tag, and keeps search open so you can add more.

    Nothing is listed twice, you drag to reorder, and the list is still there when you restart Sholto.

    DROP 16 Section map

    See the whole song, phrase by phrase

    The strip above each waveform names every section and its length in bars, like DROP 16, with faint lines every 8, 16 and 32 bars. You see the next phrase coming before you hear it.

    Pick your waveform: 3-BAND stacks bass, mids and highs as layers. RGB colours each fine stripe by what is playing at that instant.

    JOG Platter

    Scratch, backspin, brake

    Rest a hand on the jog wheel and the record holds. Turn it and the sound follows your hand. Fling it and let go for a backspin.

    Two Platter feel knobs set how long the spin lasts and how far it rewinds, counted in beats so it follows the tempo.

    ⛓ Beat-snap

    Beats that snap together

    Bring two tracks close and the jog wheel holds on the beat. Let go and they lock, tempo included. Nothing to arm.

    DDJ-FLX4 Controller

    Your controller, drawn on screen

    Plug in a Pioneer DDJ-FLX4 and it just works. Click any control on the drawing, or press it on the real thing, to see what it does, including the Shift combinations. Controls Sholto does not use stay grey.

    #themes Themes

    Make it yours

    Eleven themes recolour everything: the library, the key chips, the section map and the waveforms. Or write your own in a small JSON file. Pick one to see it.

    Settings ▸ Layout Wizard

    Try them all on first

    The Layout Wizard puts each theme on the whole app as you move through the gallery. Nothing is kept until you press Apply, and Esc puts back what you had.

    ⏎ Install

    One command

    It downloads the latest release into ~/sholto, installs the tools it needs (it asks for your password once) and starts Sholto. Run it again to update.

    Terminal · Ubuntu, Mint, Pop!_OS or Debian
    $ curl -fsSL https://raw.githubusercontent.com/freedomfirst26/Sholto/main/get-sholto.sh | bash
    1. 1Finds the newest release on GitHub and downloads it, about 43 MB.
    2. 2Installs ffmpeg, the beat detector (madmom) and stem separation (demucs).
    3. 3Starts Sholto. It scans your Music folder; press 1 or 2 to load a track.
    Download it by hand 
    mkdir -p ~/sholto
tar -xzf ~/Downloads/sholto-*-linux-x64.tar.gz -C ~/sholto
cd ~/sholto
bash install-deps.sh
./Sholto
    Build from source 
    git clone https://github.com/freedomfirst26/Sholto.git
cd Sholto
bash install.sh
dotnet run -c Release --project src/Sholto.Interface.MainUI

    What you need

    Computer
    64-bit Linux with a desktop and sound. Ubuntu, Mint, Pop!_OS or Debian for the installer.

    Pioneer DDJ-FLX4, optional. Mouse and keyboard work.

    Optional. An NVIDIA card makes stem separation faster.

    About 250 MB per track for stems, kept so they load instantly next time.

    Before you install

    Is it really free?

    Yes, for everyone: paid gigs, streaming, teaching, and clubs or bars running it for their DJs. Sholto is source-available. Anything that competes with it (selling copies, rebranding, hosting it, or bundling it with hardware or another product) needs a commercial licence: freedomfirst26@proton.me. The beat detector (madmom) has non-commercial models under their own licence, which Sholto’s licence does not cover.

    Do I need a DDJ-FLX4?

    No. Everything works from the mouse and keyboard. Plug the FLX4 in at any time and a green dot in the top bar shows it is connected.

    Windows or macOS?

    Not yet. Sholto runs on 64-bit Linux today. Windows, macOS and more controllers are on the way.

    What music does it play?

    mp3, FLAC, WAV, AIFF and M4A/AAC from your own music folder. It analyses each track once for beats, tempo and key, then remembers.

    Something did not install. How do I check?

    Run bash install-deps.sh --verify in ~/sholto. It runs each tool for real and tells you which one is broken and what you lose without it. In the app, the status dot turns amber and lists the same.

    How do I update?

    Run the same install command again. It skips the download if you already have the newest release.
